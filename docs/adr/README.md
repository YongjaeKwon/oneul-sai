# ADR (Architecture Decision Records)

프로젝트의 주요 아키텍처 결정을 기록한다. 각 ADR은 "왜 이 결정을 했는가"에 집중하며, 결정이 뒤집히면 새 ADR로 대체하고 기존 문서는 상태만 변경한다(삭제하지 않는다).

- 파일명 규칙: `ADR-00X-kebab-slug.md`
- 상태: `Proposed` → `Accepted` → (필요 시) `Superseded by ADR-0YY`
