# 운영 중 사이트 사실표 — onulsai.site 공개 문구와 저장소 문서 대조

같은 서비스를 **친구가 따로 만들어 운영 중인 사이트 <https://onulsai.site/>** 의 공개 문구를 모아, 저장소 문서의 지금 문장과 대조한 표다. 이 저장소는 그 사이트를 대체 · 이관하는 것이 아니라 **독립 구현 — 기능 동등 · 방침 일치**로 만든다(이관은 선택지 하나일 뿐이다).

- 상태: 확정
- 최종 갱신: 2026-10-14 (처음 작성 — 2026-10-13 캡처 기준. 2026-10-14 결정 Q1 · Q2 · Q5 반영)
- 원천 지위: **운영 방침 문장**(참가비 · 환불 · 최소 인원 · 보관 기간 · 참가 조건 · 동의)은 이 표의 사이트 문구가 원천이다(사용자 확인 2026-10-13, [AGENTS.md](../../AGENTS.md) 3장 원칙 8). 팜플렛 · 운영 메시지와 충돌하면 사이트가 이긴다. **구조**(로그인 · 식별 수단 · 서비스 경계 · 상태 머신)와 **디자인**(글꼴 · 색)은 이 규칙 밖이다 — 구조는 우리가 정하고(ADR · 설계서), 디자인은 결정 필요([디자인 파운데이션](../design/design-foundation.md) 10절).
- 캡처: 2026-10-13 13:28~13:31, 공개 GET만 — `/`, `/apply`, `/apply/5` · `/apply/6` · `/apply/7`, `/pool/register`, `/admin/login`. **`/admin` 뒤와 제출 뒤 화면은 보지 못했고** 사용자도 들어갈 수 없다(운영자 내부 흐름은 2절 "운영자(친구)에게 물을 것"). 캡처 파일은 저장소에 두지 않는다. 정책 문장은 글자 그대로 여기에 인용하고, 그 밖의 문구(입력 안내 · 홍보 문구)는 사실 확인에 필요한 최소 범위만 이 파일에 인용하며 다른 문서로 옮기지 않는다. 사이트의 CSS · 글꼴은 가져오지 않는다.
- 저장소 쪽 줄 번호(1절 "저장소 문서의 지금 문장")는 `main fe51be9`(2026-10-14 docs PR 1 전) 기준이다. 그 PR이 고친 문장은 줄이 달라졌을 수 있다 — 경로와 인용 문구로 찾는다.
- 갱신: 사이트가 바뀌면 바뀐 행에 새 캡처 날짜를 붙여 고친다. 날짜가 없는 행은 2026-10-13 캡처다.

## 3. 우리가 정한 것 (사이트와 다를 수 있음)

## 4. 사용 규칙

- 설계서 · 기능 소개서 · 용어 사전이 사이트 문구를 근거로 쓸 때는 **이 파일의 행 번호를 인용한다**(예: "site-facts 1절 7번"). 캡처 파일 줄 번호는 저장소에 없으므로 쓰지 않는다.
- 정책 문장은 **글자 그대로** 옮긴다. 다듬어 쓰면 원문이 아니다 — 저장소 문체로 고쳐 쓰는 곳(기능 소개서)에서는 이 파일의 원문을 함께 가리킨다.
- 사이트가 바뀌었음을 알게 되면 바뀐 행에 캡처 날짜를 붙여 고치고, 그 행을 인용한 문서를 같은 PR에서 함께 본다.
- 공개 영역 밖의 사실(2절)은 운영자(친구)의 답을 받기 전까지 **[추정]** 으로만 적는다.
