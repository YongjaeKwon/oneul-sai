# 기능 소개서

기능 소개서는 오늘사이의 기능 하나를 **사용자 관점**에서 설명하는 문서입니다. 개발자가 아닌 분도 읽습니다. 운영자가 참가자에게 설명할 때, 새 팀원이 서비스를 이해할 때 이 문서를 봅니다.

- 상태: 확정
- 최종 갱신: 2026-09-23 (Step 1 기능 소개서 2건 추가)
- 템플릿: [TEMPLATE.md](./TEMPLATE.md)
- 기술 내용은 [기능 설계서](../../specs/README.md)에 있습니다. 이 문서에는 넣지 않습니다.

## 1. 쓰는 방법

| 항목      | 규칙                                                                                                                  |
| --------- | --------------------------------------------------------------------------------------------------------------------- |
| 단위      | 기능 하나당 문서 하나                                                                                                 |
| 파일명    | 영어 kebab-case. 예: `today.md`, `one-more.md`, `check-in.md`                                                         |
| 문체      | 정중한 존댓말. 따뜻하고 짧은 문장                                                                                     |
| 약속 문구 | 팜플렛 문구를 그대로 씁니다. 바꾸지 않습니다. 예: "서로 선택한 경우에만 연결됩니다", "양쪽 모두 원할 때만 연결됩니다" |
| 브랜드    | 오늘사이(붙여쓰기), 영문 ONULSAI                                                                                      |
| 시점      | 설계서가 확정되면 초안을 씁니다. 기능이 배포되면 실제 화면에 맞춰 확정합니다                                          |
| 미정      | 아직 정해지지 않은 규칙은 "결정 예정"이라고 쓰고 어느 Step에서 정해지는지 적습니다                                    |

## 2. 오늘사이의 네 가지 개념

팜플렛 순서 그대로입니다. 태그라인은 "오늘, 우리 사이의 시작."입니다.

| 개념         | 한 줄                                                                                                                                                | 약속                            |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| **TODAY**    | 오늘, 직접 만나보세요. 일요일 카페에서 7명과 한 사람씩 1:1로 대화하고, 당일 호감을 선택합니다                                                        | 서로 선택한 경우에만 연결됩니다 |
| **ONE MORE** | 아쉬운 사람이 있었다면, 한 번 더. 집에 돌아간 뒤에도 생각나는 사람이 있다면, 오늘 만난 사람 중 딱 한 사람에게 한 번 더 마음을 전달해 드립니다        | 상대방도 원할 때만 연결됩니다   |
| **AFTER**    | 오늘 없었다면, 다음 인연까지. 희망하는 분만 AFTER에 등록합니다. 새로운 참가자 중 원하는 조건과 잘 맞는 분이 있으면 오늘사이가 다시 소개를 제안합니다 | 양쪽 모두 원할 때만 연결됩니다  |
| **NEXT**     | 새로운 만남으로, 다시 한 번. 이번에 인연을 만나지 못했다면 재참가 혜택으로 새로운 일요일, 새로운 7명과 다시 시작할 수 있습니다                       | —                               |

## 4. 현재 운영 방식 (참고)

지금은 시스템 없이 운영자가 직접 진행합니다. 기능 소개서를 쓸 때 이 흐름이 출발점입니다.

1. 참가자가 참가를 신청합니다.
2. 계좌이체로 입금합니다.
3. 운영자가 입금을 확인하면 카카오 알림톡으로 참가 확정을 안내합니다.
4. 정확한 장소와 준비 사항은 행사 전에 다시 안내합니다.
5. 행사 당일, 출생연도와 본인 확인이 가능한 신분증을 지참합니다.

참가 확정 알림톡 문구(실제 사용 중):

> [오늘사이 참가 확정] [이름]님, 입금이 확인되어 10/4(일) [14:00] 참가가 확정되었습니다. 정확한 장소와 준비 사항은 행사 전에 다시 안내드릴게요. 행사 당일에는 출생연도와 본인 확인이 가능한 신분증을 지참해 주세요. 함께하게 되어 반갑습니다!

결제는 초기에는 입금 확인 기반입니다. PG 연동은 이후 단계에서 결정합니다 (Step 4).
