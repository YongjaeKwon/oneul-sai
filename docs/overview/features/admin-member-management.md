# 운영자 회원 관리

- 상태: 초안 (실제 화면 확인 뒤 확정)
- 최종 갱신: 2026-09-23
- 관련 Step: Step 1
- 팜플렛 개념: 운영 기능

## 1. 이 기능은 무엇인가요

운영자가 운영자 웹에 로그인해 회원을 찾아보고, 필요할 때 계정을 정지하거나 정지를 풀 수 있습니다.

## 2. 누가 쓰나요

| 누가   | 언제                                                                                                                            |
| ------ | ------------------------------------------------------------------------------------------------------------------------------- |
| 참가자 | 쓰지 않습니다. 참가자는 [회원가입과 로그인](./signup-login.md)의 참가자 웹을 씁니다.                                            |
| 운영자 | 문의가 들어와 회원을 확인할 때, 신청 · 입금을 대조할 때, 문제가 있는 계정을 정지하거나 정지를 풀 때. 지금은 이 세 가지뿐입니다. |

## 3. 화면과 흐름

1. **로그인** — 이메일과 비밀번호를 입력합니다. 운영자 계정이 아니면 "운영자 계정이 아닙니다."라고 안내하고 로그인되지 않습니다. 비밀번호를 여러 번 틀렸을 때 늦어지는 규칙은 참가자와 같습니다(운영자 계정도 잠기지 않습니다).
2. **회원 목록** — 로그인하면 바로 회원 목록이 보입니다. 검색어(이메일 · 이름 일부, 휴대폰 앞자리)와 상태 · 역할 필터로 좁히고, 페이지를 넘깁니다. 한 줄에 이름, 이메일, 휴대폰, 성별, 출생연도, 역할, 상태, 가입일이 보입니다. 같은 휴대폰 번호로 여러 계정이 있으면 함께 보입니다.
3. **회원 상세** — 프로필 전체, 동의한 시각, 로그인 실패 횟수와 마지막 실패 시각(읽기 전용), 현재 상태와 사유를 봅니다. 탈퇴한 회원은 이름 · 성별 · 출생연도 · 휴대폰이 지워진 채로 보이고 상태를 바꿀 수 없습니다.
4. **정지 / 정지 해제** — 상세 화면에서 "정지" 또는 "정지 해제"를 누르고 사유를 적은 뒤 확인합니다. 정지 사유는 필수, 해제 사유는 선택입니다. 정지하면 "계정을 정지했습니다. 이 회원의 모든 세션이 끊겼습니다.", 해제하면 "정지를 해제했습니다. 이 회원은 다시 로그인할 수 있습니다."라고 안내합니다. 사유는 상세 화면에 남습니다.

운영자 웹에서 이름 · 성별 · 출생연도를 고치는 화면은 아직 없습니다. Step 1 동안은 문의를 받아 개발자가 직접 고칩니다(정정 화면과 변경 이력은 결정 예정 (Step 5)). 현장 본인 확인(신분증)은 여기서 기록하지 않고 Step 5의 체크인 화면에서 참가자 · 일정 단위로 기록합니다.

## 4. 규칙

- 운영자 계정은 가입 화면으로 만들 수 없습니다. 개발자가 따로 만들어 드리며, 비밀번호 교체도 같은 절차로 합니다(교체하면 그 운영자의 기존 로그인은 모두 끊깁니다).
- 운영자도 회원과 같은 로그인 규칙을 따릅니다. 비밀번호를 여러 번 틀리면 다음 시도가 늦어질 뿐 잠기지 않습니다.
- 운영자 웹의 로그인은 운영자 웹 주소에서만 됩니다. 참가자 웹과 운영자 웹에 한 브라우저로 동시에 로그인해도 서로 간섭하지 않습니다.
- 자기 자신의 계정은 정지할 수 없습니다.
- 정지하면 그 회원은 바로 로그인할 수 없고, 이미 로그인된 기기도 모두 끊깁니다. 참가자 화면에는 "이용이 정지된 계정입니다. 오늘사이에 문의해 주세요."가 보입니다. 정지 해제는 같은 화면에서 합니다.
- 탈퇴한 회원의 상태는 바꿀 수 없습니다. 운영자가 회원을 대신 탈퇴시키는 기능은 결정 예정 (Step 5)입니다.
- 누가 언제 어느 회원의 정보를 봤는지 기록이 남습니다(개인정보 열람 기록). 검색어 자체는 남기지 않습니다.
- 회원 목록 · 상세에는 비밀번호가 어떤 형태로도 보이지 않습니다.

## 5. 자주 묻는 질문

**Q.** 회원이 이름을 잘못 적었다고 문의했어요.

**A.** 아직 화면에서 고칠 수 없습니다. 개발자에게 정정을 요청해 주세요. 정정 화면은 결정 예정 (Step 5)입니다.

**Q.** 정지한 회원이 지금 로그인돼 있으면 어떻게 되나요?

**A.** 정지 즉시 그 회원의 모든 로그인이 끊깁니다. 이미 열려 있던 화면도 다음 요청부터 막힙니다(최대 15분 안에 확실히 끊깁니다).

**Q.** 회원이 비밀번호를 잊어버렸다고 해요.

**A.** 아직 재설정 기능이 없습니다(결정 예정 (Step 7)). 운영자 웹에서도 회원의 비밀번호를 바꿔 줄 수 없습니다.

**Q.** 같은 휴대폰 번호로 계정이 두 개 보여요.

**A.** 정상입니다. 휴대폰 번호는 계정마다 달라야 하는 값이 아니어서 중복 가입이 함께 보입니다. 휴대폰 인증이 생기면(결정 예정 (Step 7 이후)) 하나로 제한할 예정입니다.
