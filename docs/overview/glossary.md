# 오늘사이 용어 사전

- 상태: 초안(리뷰 후 확정)
- 최종 갱신: 2026-09-23 (Step 1 구현에 맞춰 용어 추가 · 코드 식별자 보강)

오늘사이에서 쓰는 말을 한 곳에 모았습니다. 운영자가 쓰는 한국어 용어와 개발자가 코드에서 쓰는 영어 이름을 짝지어 두었습니다. 서로 다른 말을 쓰고 있다면 이 표로 맞춥니다.

- 새 용어가 생기면 이 문서에 먼저 추가하고 코드 이름을 정합니다.
- 아직 정하지 않은 이름은 "결정 예정"과 함께 정할 로드맵 단계를 적습니다. 로드맵은 [개요 소개서 5장](./project-overview.md#5-지금-어디까지-왔나)에 있습니다.
- 표기 규칙: 브랜드명은 **오늘사이**로 붙여 씁니다. 영문은 **ONULSAI**입니다.

## 5. 헷갈리기 쉬운 말

**"이벤트"는 두 가지 뜻으로 쓰입니다.**

| 이 말이 나왔을 때                                                   | 뜻                                                                                                       | 구별법                               |
| ------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| 이벤트 서비스, `event-service`, `/api/v1/events`, `event.started`   | **행사**(소개팅 모임)를 말합니다. 모임 상품·일정·신청·체크인·로테이션을 맡는 서비스입니다.               | 사람이 모이는 일요일의 그 행사       |
| Kafka 이벤트, `EventEnvelope`, `match.created`, "이벤트를 발행한다" | **시스템 안의 알림 메시지**를 말합니다. "매칭이 만들어졌다" 같은 사건을 다른 서비스에 전하는 편지입니다. | 사람은 볼 수 없는, 서비스끼리의 쪽지 |

문서와 대화에서는 행사는 되도록 **"행사"** 또는 **"일정"**, 시스템 메시지는 **"Kafka 이벤트"**라고 부르면 오해가 줄어듭니다. 코드 이름(`event-service`)은 이미 정해져 있어 바꾸지 않습니다.

**그 밖에 자주 섞이는 말**

| 이렇게 쓰지 않기     | 이렇게 쓰기                                                  | 이유                                                                                                         |
| -------------------- | ------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------ |
| 오늘 사이 (띄어쓰기) | 오늘사이                                                     | 브랜드명은 항상 붙여 씁니다.                                                                                 |
| 회원 = 참가자        | 회원은 가입한 사람, 참가자는 특정 일정에 확정된 사람         | 회원은 `Member`(member-service), 참가자는 `Participant`(event-service)로 다른 서비스에 있습니다.             |
| 신청 = 확정          | 신청은 입금 전, 확정은 입금 확인 후                          | 알림톡은 확정 시점에만 나갑니다.                                                                             |
| 매칭 = 로테이션 짝   | 로테이션 짝은 당일 대화 상대, 매칭은 서로 선택해 연결된 결과 | 로테이션은 event-service, 매칭은 matching-service입니다.                                                     |
| PG = 게이트웨이      | PG는 결제 대행사, 게이트웨이는 우리 서버의 창구              | 이름만 비슷하고 전혀 다른 것입니다.                                                                          |
| 계정 잠금            | 로그인 백오프 (기다리게 할 뿐 잠그지 않음)                   | 오늘사이는 계정을 잠그지 않습니다. 여러 번 틀리면 다음 시도가 느려질 뿐이고, 운영자가 풀어 줄 것도 없습니다. |
