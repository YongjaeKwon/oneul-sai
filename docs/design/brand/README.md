# 브랜드 원본 자산

마케팅에 실제로 쓰는 로고·팜플렛 원본을 여기에 둔다. 코드에서 직접 참조하지 않고, 디자인 작업 시 기준으로 본다.

| 파일 (예정)                 | 내용                                                            |
| --------------------------- | --------------------------------------------------------------- |
| `logo-circle.png`           | 원형 로즈 테두리 배지형 로고 (알림톡 프로필·SNS 프로필용)       |
| `logo-mark.svg`             | 겹치는 두 원 마크 단독                                          |
| `pamphlet-01-intro.png`     | "7명을 만나고, 끝?" 표지 — TODAY · ONE MORE · AFTER · NEXT 소개 |
| `pamphlet-02-today.png`     | TODAY — 오늘, 직접 만나보세요                                   |
| `pamphlet-03-one-more.png`  | ONE MORE — 아쉬운 사람이 있었다면, 한 번 더                     |
| `pamphlet-04-after.png`     | AFTER — 오늘 없었다면, 다음 인연까지                            |
| `pamphlet-05-next.png`      | NEXT — 새로운 만남으로, 다시 한 번                              |
| `kakao-confirm-message.png` | 카카오 알림톡 참가 확정 메시지 캡처                             |

원본 파일은 저장소에 아직 없다. 운영자가 보관 중인 원본을 위 이름으로 복사해 넣으면 된다.
파일에서 뽑아낸 색·글꼴·구성 규칙은 [design-foundation.md](../design-foundation.md)에 정리되어 있다.
